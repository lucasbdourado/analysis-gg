# Runeterra Arena Design System

This folder contains a reusable static design reference inspired by the public League of Legends website. It does not copy proprietary artwork, logos, or exact layouts from the reference.

## Files

- `design-doc.html` - visual documentation, research notes, palette, typography, components, accessibility, and responsive rules.
- `tokens.css` - semantic color, typography, spacing, radius, shadow, motion, and z-index tokens.
- `typography.css` - text hierarchy, heading styles, body copy, links, and labels.
- `components.css` - buttons, navigation, panels, cards, badges, alerts, fields, tabs, tables, and modal styles.
- Patch note components are included for article headers, metadata, editorial intros, patch summaries, repeated change entries, icons, and change lists.
- `layout.css` - page structure, containers, hero, grids, split layouts, and breakpoints.
- `examples.html` - practical static examples using the CSS files.

## Preview

Open `design-doc.html` or `examples.html` in a browser. These files are static and do not require a dev server.

## Usage Notes

Use this system for cinematic game portals, competitive dashboards, champion or character libraries, update hubs, and event pages. Keep hero sections immersive, but keep functional surfaces compact and scannable.

The patch note pattern was expanded from the public Patch 26.11 notes page. It is suitable for long-form update articles with sectioned gameplay changes, author/date metadata, designer commentary, balance entries, bug fixes, and future cosmetic release notes.

Gold is reserved for prestige and primary calls to action. Cyan is reserved for active digital affordances, links, and secondary actions. Crimson is reserved for urgent or destructive states.

Do not use League of Legends logos, screenshots, champion art, or branded assets unless the product owner has explicit rights to use them.
