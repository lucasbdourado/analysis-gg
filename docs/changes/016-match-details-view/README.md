# 016 - Match Details View

This folder contains the research and development specification for the Match Details View change.

## Why this exists

This spec was created to gather and organize the relevant context before development, including product expectations, observed behavior, code research, risks, questions, decisions and development guidance.

## Main sources

- User Request: Accessing each match to see detailed stats (overview, players, items, CS, KDA, runes, and spells) on a new page/route.
- Riot Games API (Match-V5)
- Spring Boot Java backend (caching and REST mapping)
- Vite + React + TS frontend (react-router-dom)
