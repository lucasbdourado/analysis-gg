# 019 - Back to Account Selection

This folder contains the research and development specification for adding a back button from the dashboard page to the account selection (search landing page).

## Why this exists

This spec was created to gather and organize the relevant context before development, ensuring the back button matches the visual style and behavior of existing navigation components in the application.
