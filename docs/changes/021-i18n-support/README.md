# 021 - Internationalization (i18n) Support

This folder contains the research and development specification for the Internationalization (i18n) Support change.

## Why this exists

This spec was created to gather and organize the relevant context before development, including product expectations, observed behavior, code research, risks, questions, decisions and development guidance.

## Main sources

- User Request: Enable multi-language support (English & Portuguese)
- Research: Frontend codebases, Recharts weekday mapping, and Session Review coaching tips
- Framework: Custom React Context + Hook implementation
