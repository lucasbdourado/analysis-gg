# 011 - Summoner Splits and Role Win Rates

This folder contains the research and development specification for the Summoner Splits and Role Win Rates change.

## Why this exists

This spec was created to gather and organize the relevant context before development, including product expectations, observed behavior, code research, risks, questions, decisions and development guidance.

- CommunityDragon Clash position icons.
- Riot Games Match-V5 API `teamPosition` field.
