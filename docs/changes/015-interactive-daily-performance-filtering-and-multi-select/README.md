# 015 - Interactive Daily Performance Filtering and Multi-Select

This folder contains the research and development specification for the Interactive Daily Performance Filtering and Multi-Select change.

## Why this exists

This spec was created to gather and organize the relevant context before development, including product expectations, observed behavior, code research, risks, questions, decisions and development guidance.
