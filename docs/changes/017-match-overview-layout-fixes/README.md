# 017 - Match Overview Layout Fixes

This folder contains the research and development specification for the **Match Overview Layout Fixes** change.

## Why this exists

The match overview page shows overlapping text and empty item slots, making the UI unreadable and visually broken. This spec gathers the context, findings, and proposed UI adjustments before implementation.
